# Copy Audit — 2026-07-21

This audit reviews existing public-facing language against `VOICE.md`. It does
not attempt to sanitize ordinary volleyball terminology or internal technical
documentation.

## Revised in product copy

| Existing phrase | Decision | Replacement | Why |
| --- | --- | --- | --- |
| `built for the queens of the court` | Blocked | `built for women who compete` | The original is patronizing and visually pushes the women's event into a separate, ornamental register. |
| `Good vibes only` | Revise | `Raises the group` | The original is a dated lifestyle cliché. |
| `Unhinged energy` | Blocked | `Sets the pace` | Keeps the competitive idea without mental-health-coded slang or an unsafe always-on identity. |
| `Menace to society` | Blocked | `Unpredictable by design` | The original makes the player identity the joke. |
| `No substitutions, no breaks, no excuses` | Revise | `Steady from the first round through the last` | The original can reward ignored limits or playing through injury. |
| `Jump serve at 110% — it’s all or nothing` | Revise | `Serve your toughest ball at a clear target` | Intensity should not be expressed as ignoring physical limits. |
| `Roll in hot, no warm-up needed` | Blocked | `Already tracked the wind and picked a serving side` | The original rewards an avoidable injury risk. |
| `Skip food. Reviewing game film.` | Blocked | `Grab food, then start swapping match clips` | Recovery is not a lack of commitment. |
| `maximum vibes` / `pure chaos` / `bigger energy` | Revise | Name the actual team behavior or moment | Generic brand slang is interchangeable with any sports account. |
| `Unapologetically competitive` | Revise | `Built to compete` | The shorter line keeps the edge without manifesto filler. |

## Keep, but control frequency

| Phrase | Decision | Guidance |
| --- | --- | --- |
| `Bring the heat` | Context | It is established Jalapeño campaign language. Use once per campaign, not on every asset. |
| `Link in bio` | Context | Valid only for temporary social placements. Never bake it into evergreen master art. |
| `Full send` | Context | Recognizable player language, but overused in brand copy. Use only in quoted participant language. |
| `Underground` | Context | Useful as an aesthetic cue, not as the main explanation of the event. Pair it with plain grass-volleyball language. |
| Pepper/heat puns | Context | One can work in an event campaign. Repetition makes the system feel themed rather than competitive. |

## Caption standard

The current reel queue repeats generic captions across many clips. Future captions
should derive from clip metadata and name the actual moment. The minimum useful
metadata is event, team, player, court, round, play type, outcome, and participant
handles.

The legacy fallback caption generator now uses neutral event language, one exact
credit format, and five relevant hashtags. It deliberately avoids pretending to know
the play. Use the Clip Desk for every new Reel so the caption can become specific.

## Current platform check

- Instagram now caps Reel/post hashtags at five. Use a small set of relevant tags;
  do not rotate unrelated beach or professional-league tags into grass footage.
  [Reported platform change](https://www.digitaltrends.com/social-media/instagram-now-limits-you-to-five-hashtags-per-post/)
- Original footage and meaningful editing matter more than swapping generic captions
  over a large batch of similar clips. Meta reports that its recommendations increasingly
  favor original work. [Meta, 2026](https://about.fb.com/news/2026/01/2026-ai-drives-performance/)
- Use Trial Reels for genuinely new formats, then compare shares, watch time, and
  follows before promoting the format to the full audience.
  [Instagram Trial Reels](https://about.fb.com/news/2024/12/trial-reels-try-content-non-followers-first-see-what-perfoms-best/)
- Check the account's Professional Dashboard before changing cadence or format; its
  Best Practices section provides current, account-specific guidance.
  [Instagram Best Practices](https://about.fb.com/news/2024/10/best-practices-education-hub-creators-instagram/)
